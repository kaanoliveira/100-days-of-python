# 100 Days of Code: Python Pro Bootcamp

This repository is a collection of the code, exercises and projects I build during
Dr. Angela Yu's *100 Days of Code: The Complete Python Pro Bootcamp*.

## About the Course

- **Instructor:** Dr. Angela Yu
- **Course:** [100 Days of Code: The Complete Python Pro Bootcamp](https://www.udemy.com/course/100-days-of-code/)
- **Duration:** 100 days, one project per day

## Goals

- Build a solid foundation in Python programming.
- Turn each concept into a working project instead of stopping at the theory.
- Develop good coding practices: clear names, small functions, readable code.

## Repository Structure

- One folder per day, named `DayNN-project-name`.
- Each folder holds the project of the day plus the smaller exercises that led to it.
- Files are named after what they do, so `hangman.py` or `leap_year.py`.
- When a project is built over several steps, the folder keeps the final version and the
  steps remain in the commit history.

## Running the Code

Python 3 is the only requirement. Each file runs on its own, for example:

    python Day07-hangman/hangman.py
